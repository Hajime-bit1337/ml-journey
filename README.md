### Проект: EDA по датасету Titanic

Разведочный анализ 891 записи о пассажирах: обработка пропусков, поиск факторов
выживаемости, проверка найденных связей на скрытые общие причины.

**Что сделано:**

- обработаны пропуски в трёх колонках, каждое решение обосновано:
  `embarked` (2 строки) заполнен модой, `deck` (77% пропусков) превращён
  в категорию «неизвестно», `age` (20%) заполнен медианой по классу
  с сохранением флага `age_missing`;
- выявлена и удалена утечка целевой переменной: колонка `alive` оказалась
  дословной копией `survived`;
- проверены факторы выживаемости: пол, класс, возраст, цена билета,
  порт посадки, наличие семьи;
- каждый найденный эффект проверен на **confounding** — сохраняется ли он
  при фиксации других факторов.

**Основные результаты:**

- пол — сильнейший отдельный фактор: 74% против 19%, разрыв сохраняется
  внутри каждого класса;
- класс: 63% / 47% / 24%, разрыв сохраняется внутри каждого пола;
- дети до 8 лет выживали в 66% случаев против 38% у взрослых;
- цена билета связана с выживанием в целом, но внутри третьего класса
  (больше половины выборки) эффект исчезает — цена работает как заменитель класса;
- пропуск в колонке `deck` сам по себе ничего не значит: палуба записана
  у 81% пассажиров первого класса и у 2% третьего.

Подробные выводы и ограничения анализа — в конце ноутбука.

## Как запустить

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter lab
```

Данные и база SQLite не хранятся в репозитории — они воспроизводятся из кода:

- датасет Titanic скачивается в первой ячейке ноутбука через `seaborn.load_dataset`;
- учебная база `sql/shop.db` создаётся скриптом `python sql/create_db.py`.
